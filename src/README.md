# NCAA Athlete Classifier Source Code

The source code for the NCAA Athlete Classifier is broken up into the following parts.

## 1. Classifiers
The classifiers are used to analyze the source images.  They output results in .json format into the file system along with the images.

### [Color Analyzer](color-analyzer)
This tool uses the Color Thief utility to find the dominant color of each image and map it to a Monk skin tone.

### [Skin Tone Analyzer](skin-tone-analyzer)
This tool uses the Skin Tone Analyzer utility to find the dominant color of the skin tone regions each image and map it to a Monk skin tone.

### [Demographic Analyzer](skin-tone-analyzer)
This tool uses the DeepFace utility to find the demographic characteristics of each image.

## 2. Data Managers

### [Data Cleanup](data-cleanup) 
This utility is used to clean up and de-duplicate the original spreadsheet data.

### [Database Initializer](database-initializer) 
This utility enters the player data from  spreadsheets into a database so that skin tone and demographic information can be appended.

### [Data Manager](data-manager)
This utility walks through the data directory after the classifiers have been run, reads the .JSON files generated by the classifiers, and enters that data into the database.

## 3. Web Utilities

### [Web Scraper](web-scraper) 
This utility can be used to download team and player images and data from the ESPN API.  If you already have the data, then you don't need to use this utility.

### [Webpage Creator](webpage-creator) 
This utility can be used to create webpages to preview results.  This is useful for analyzing the accuracy of the skin tone classifiers.
